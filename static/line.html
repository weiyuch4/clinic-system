LINE Messaging API 憑證
從 LINE Developers Console 取得，套用後立即生效。憑證儲存於伺服器，不會顯示在瀏覽器。
推播訊息範本
當病患已綁定 LINE 帳號時，系統會直接傳送以下訊息，不再需要透過 AlleyPin 自動化。
若留空，系統將使用預設訊息。
病患綁定連結
將此連結製作成 QR Code 或放在診所網站，病患掃描後輸入病歷號碼即可完成綁定。
或使用 LIFF 連結（在 LINE 內開啟）：
—
已綁定病患
綁定名單
病歷號碼 LINE 顯示名稱 綁定時間
載入中…
傳送綁定邀請
向所有已綁定的病患傳送訊息，提醒他們確認綁定仍有效。適合在切換系統後驗證用。
注意：此功能對象是已綁定名單中的病患，尚未綁定的追蹤者需要自行掃描 QR Code 完成綁定。
從 CSV 匯入綁定資料
此功能僅適用於您已有 病歷號碼 ↔ LINE User ID 對應資料的情況（例如從舊系統匯出）。
AlleyPin 的匯出檔案不含 LINE User ID（只有系統內部 ID），無法直接匯入。
若要將現有的 LINE 追蹤者綁定到此系統，病患需掃描 QR Code 自行完成綁定。
CSV 格式：第一行為標題列，需包含 chart_number（病歷號碼）和 line_user_id 兩個欄位。
選填欄位：display_name（LINE 顯示名稱）。
